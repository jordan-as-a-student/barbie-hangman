# 🎀 Barbie Hangman: Dress Up & Guess

A highly customized, fully responsive, Barbie-themed Hangman web application! This project takes the classic Hangman game and gives it a glamorous makeover, featuring a custom character selection screen, interactive UI logic, and a dynamic "Barbie Box" layout.

## ✨ Features

*   **Choose My Barbie:** A dedicated starting screen where players can name their Barbie and select their character from a scrolling picture carousel before the game begins.
*   **The Barbie Box:** Instead of a traditional gallows, your selected Barbie stands inside a classic toy box.
*   **Win Animation:** When you guess the word correctly, your chosen Barbie physically steps out of the box to celebrate!
*   **Glamorous UI:** Features 3D gradients, drop shadows, readable modern typography for the keyboard, and beautiful cursive script for headers.
*   **Fully Responsive:** Designed with Flexbox to look amazing on both desktop monitors and mobile phone screens.

## 🛠️ Built With

*   **[React 19](https://react.dev/)** - Core framework for UI components and game state logic.
*   **[Vite](https://vitejs.dev/)** - Lightning-fast frontend build tool and development server.
*   **Vanilla CSS** - Custom styles, 3D gradients, Z-index layering, and CSS animations.
*   **JavaScript (ES6+)** - Powers the Hangman logic, keyboard, and character selection data.

## 🚀 How to Run Locally

If you want to download and play this game on your own computer:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/jordan-as-a-student/barbie-hangman.git
   ```
2. Navigate into the project folder:
   ```bash
   cd barbie-hangman
   ```
3. Install the dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open your browser and visit the local link provided in your terminal (usually `http://localhost:5173`).
